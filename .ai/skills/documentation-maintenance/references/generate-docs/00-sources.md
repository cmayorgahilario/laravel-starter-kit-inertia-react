# §0 — Sources and their trust hierarchy

- THE REPO CODE IS THE ONLY SOURCE OF TRUTH. In any conflict, the repo wins. If there are no other
  inputs, generate all the documentation by reading the repo directly.
- Optional drafts (if present): a potentially contradictory and outdated starting point. An
  accelerator, NOT truth nor a requirement.
- Existing previous documentation (if any): a template of STRUCTURE and CONVENTIONS only. Its CONTENT
  may describe another stack/state → NEVER copy it as fact. Reuse the pattern, rewrite the content.
