# Frontend

**Why it exists:** explain the client-side application — how it boots, how pages and layouts are
organized, how it talks to the backend and how it is styled.
**Covers:** the entrypoint, the folder structure, Wayfinder routing, the UI component system and the
styling/theme.
**Does not cover:** the backend controllers that render the pages (see
[../architecture/app-bootstrap.md](../architecture/app-bootstrap.md)) or authentication
(see [../authentication/index.md](../authentication/index.md)).

## Overview

The SPA is **Inertia.js v3 + React 19 + TypeScript**, bundled with **Vite 8**. There is no SSR: pages
render purely on the client. The UI is built with **shadcn/ui on Base UI** and **Tailwind CSS 4**.
Backend routes are consumed through typed functions generated by **Wayfinder**.

The entrypoint is `resources/js/app.tsx`. It creates the Inertia app, resolves pages from
`resources/js/pages/{name}.tsx`, mounts global providers (`TooltipProvider`, `Toaster`) and initializes
the theme. The Blade root view is `resources/views/app.blade.php`.

## Path aliases

`tsconfig.json` and `components.json` define the import aliases:

| Alias             | Target                       |
| ----------------- | ---------------------------- |
| `@/*`             | `resources/js/*`             |
| `@/components`    | `resources/js/components`    |
| `@/components/ui` | `resources/js/components/ui` |
| `@/lib`           | `resources/js/lib`           |
| `@/hooks`         | `resources/js/hooks`         |
| `@/lib/utils`     | `resources/js/lib/utils.ts`  |

The Vite pipeline (`vite.config.ts`) wires the Laravel plugin, Inertia, React (with the React Compiler
via Babel), Tailwind 4 and the Wayfinder plugin (with form variants).
