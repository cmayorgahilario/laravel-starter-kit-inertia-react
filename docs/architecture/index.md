# Architecture

**Why it exists:** explain how the application is wired end to end: what the boot process configures,
which providers register and under which convention the code is organized.
**Covers:** high-level structure, bootstrap (`bootstrap/app.php`), providers, middleware, exception
handling and the domain organization convention.
**Does not cover:** the detail of each service (see [../services/index.md](../services/index.md)),
authentication (see [../authentication/index.md](../authentication/index.md)) or the frontend (see
[../frontend/index.md](../frontend/index.md)).

## Overview

Laravel Starter Kit is a Laravel monolith with two UI fronts:

- an **Inertia + React SPA** for end users (welcome, dashboard, user control panel and the
  authentication flow);
- a **Filament panel** at `/admin` for administration.

The backend is organized by **bounded-context** (currently `Security`), both in `app/` and in the
tests. Frontend↔backend communication uses typed routes generated by Wayfinder.

## High-level structure

| Folder           | Role                                                                       |
| ---------------- | -------------------------------------------------------------------------- |
| `app/Actions/`   | Fortify actions (user creation, profile, passwords).                       |
| `app/Filament/`  | Admin panel resources, pages and schemas.                                  |
| `app/Http/`      | Inertia controllers and middleware.                                        |
| `app/Models/`    | Eloquent models (per domain).                                              |
| `app/Providers/` | Service providers (app, Fortify, Filament).                                |
| `routes/`        | `web.php`, `api.php`, `console.php`.                                       |
| `resources/js/`  | The Inertia + React SPA.                                                   |
| `resources/css/` | Tailwind 4 and the theme.                                                  |
| `database/`      | Migrations, factories and seeders.                                         |
| `operations/`    | One-time operations (`laravel-one-time-operations`).                       |
| `config/`        | Configuration (includes `avatars.php`, `inertia.php`, `trustedproxy.php`). |
